# Project-2-Part-2-Web-Scraped-Data-Analysis-and-Visualizations

Project Purpose:
The purpose of this project is to collect and analyze NBA team statistics from the 2021-2025 seasons using web scraping. The data was collected from the ESPN stats webpage and the use of Python to then organize the data into a data frame using pandas. After cleaning the data, I then analyzed the team performance in points, rebounds, and assists per game.
